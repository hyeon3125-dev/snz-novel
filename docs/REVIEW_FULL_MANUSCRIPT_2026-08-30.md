# SCALAR: NODE ZERO v3 전권 적대 리뷰·퇴고 영수증

## 판정

- 기준 커밋: `8672db6` (`docs: record Node Zero story objective`)
- 대상: 한국어 정본 Part 1~5 전권과 이에 종속된 EN/JP 구조 번역본
- 한국어 판정: P0 0, 확인된 P1 전부 수정, 정본 후보
- 승인 경계: 외부 블라인드 리딩 전에는 새 `approved` 판정이나 버전 태그를 만들지 않는다.

`33c77a3`의 v3 문학판과 기존 구조 CI는 이미 있었지만, FSN 퇴고와 같은 고정 기준선·전권 적대 재독·패턴 전후 계측은 없었다. 이번 리비전은 그 누락분을 닫는다. 구조 검사의 PASS를 문학적 승인으로 대신하지 않는다.

## 검토 방법

1. 한국어 5부를 두 구간으로 나눈 독립 재독 두 번과 전권 단일 재독 한 번을 수행했다.
2. 시간·정보 접근·물건 소유권·인물 생사·시점 침범·정확한 대가·결말 인과를 P0/P1로 우선 검증했다.
3. Story Harness의 문체 계기판과 목적함수 렌즈는 후보 탐지와 질문 생성에만 썼다. 수치가 원고를 승인하거나 문학적 완성도를 채점하지 않는다.
4. 수정 뒤 정본 재빌드·원문 위치 무결성·복선·그래프·봉인·완주 검사를 다시 수행했다.

재현 명령:

```bash
python3 ../scalar-story-harness/scripts/prose_audit.py style \
  manuscript/SNZ_KO_Part1.md manuscript/SNZ_KO_Part2.md manuscript/SNZ_KO_Part3.md \

python3 ../scalar-story-harness/scripts/objective_audit.py audit \
  manuscript/SNZ_KO_Part1.md manuscript/SNZ_KO_Part2.md manuscript/SNZ_KO_Part3.md \
  manuscript/SNZ_KO_Part4.md manuscript/SNZ_KO_Part5.md --objectives objectives.json
```

## 정본 판정과 인접 바이블 드리프트

- 가등의 수첩은 `사건은 아직이다.` / `사건은 보고됐다.`를 현행 정본으로 유지한다. 도희는 면직 상태이므로 화감 사무실에 직접 들어가지 않고 외부 인계실에서 받는다. 누가 옮겼는지는 확정하지 않아 가등이 책상 가운데 남긴 행동의 주체도 바꾸지 않는다.
- 무율의 마지막 입력은 `보류 책임: 무율.`로 Part 4와 Part 5를 통일한다. 보류를 익명 상태가 아니라 자기가 감당할 행위로 만드는 현재 결말 방향을 우선한다.
- `Cycle 1~7`은 시설 내부의 불완전한 레이블로만 제시한다. 이를 전역 반복의 총횟수라고 본문이나 리뷰가 확정하지 않는다. 블라인드 독자가 전역 7회로 읽는지는 별도 질문으로 확인한다.
- 인접 저장소의 `SNZ WorldBible v3_0.md`와 `canon_registry.json`에는 앞의 가등·무율 문구가 구판 형태로 남아 있다. 그 저장소의 동시 작업을 건드리지 않기 위해 이번 커밋에는 포함하지 않으며, 이후 정본 문구만 별도 동기화해야 한다.

## 목적함수 경계

`objectives.json`의 독자 약속은 “답을 독점하려는 세계에서 기록·비선택·관계가 누구의 자리를 남기는지 끝까지 체감하게 하는 심리 SF”다. 목적함수 감사는 이 약속, 감정적 보상, 인물 애착, 아크별 지불 여부를 묻되 정합성 게이트와 합산하지 않는다.

기계 검사는 독자 반응을 증명하지 못한다. `BLIND_READER_QUESTIONNAIRE.md`에 Observer 해석, ARIA의 정확한 비용, 한결의 증인 역할, 네 계승선, 결말 식탁과 물건의 시간·소유권을 묻는 질문을 고정했다.
