# SCALAR: NODE ZERO v3 한국어 정본 — 블라인드 리더 설문

`manuscript/SNZ_KO_Part1.md`부터 `Part5.md`까지 순서대로 읽는다. World Bible, 리뷰 문서, 문체 계측표는 먼저 보지 않는다. 문제를 지적할 때는 Part·Ch와 가장 짧은 근거 문장을 함께 적는다.

## 서사·인물

1. Observer를 숨은 악역, 시스템의 대리인, 실패한 선행자 중 무엇에 가깝게 읽었는가. 그렇게 읽힌 최초 장면은 어디인가.
2. ARIA가 마지막에 보존한 것과 지불한 것을 각각 한 문장으로 설명할 수 있는가.
3. 한결은 ARIA의 기억을 대신 소유하거나 해석하는가, 아니면 그녀가 선택했다는 사실만 증언하는가.
4. 가등·티코·무율·율리우스의 마지막 행동이 도희·민시우·강위·클레르에게 무엇을 넘겼는지 설명할 수 있는가.
5. 네 가문 인물이 기능 설명용 도구가 아니라 각자 욕망과 비용을 가진 사람으로 보이는가. 가장 약한 한 명을 고르고 이유를 적는다.
6. `7-7-4`, 두 렌즈, Logbook, 미완료 집행 로그, `계산 중`의 소유권과 시간 순서가 혼동된 지점이 있었는가. `Cycle 7`을 전역 반복 총횟수로 읽었는지도 적는다.
7. 마지막 세 그릇과 식탁 장면이 결말로 충분한가, 아니면 설명이 더 필요한가.

## 문체·호흡

1. `기록`, `확인`, `봤다`, 부정형 종결이 주제적 반복을 넘어 기계적으로 느껴진 장면을 표시한다.
2. 인물들이 모두 같은 검증·선택 문법으로 말한다고 느껴진 곳을 표시한다.
3. 관측 가능한 행동보다 서술자가 인물의 속뜻을 먼저 확정한 문장을 표시한다.
4. 가장 느린 세 구간을 고르고 원인이 중복, 새 정보 부족, 장면 전환, 문장 리듬 중 무엇인지 적는다.

## 필수 최종 답변

- `observer_read_clear`: yes / no
- `hidden_villain_reading`: yes / no
- `exact_cost_clear`: yes / no
- `aria_has_agency`: yes / no
- `hangyeol_witness_not_owner`: yes / no
- `four_lines_feel_human`: yes / no
- `ending_lands`: yes / no
- `unresolved_p0_count`: integer
- `unresolved_p1_voice_count`: integer
- `recommend_canonical_candidate`: yes / no

`no`에는 반드시 가장 짧은 본문 근거를 붙인다. 정본이나 설정 사실이 확실하지 않으면 추측하지 말고 `canon adjudication required`로 표시한다.
